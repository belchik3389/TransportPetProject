# TransportPetProject

## Цель проекта
Применить теоретические знания на практике, научиться проектировать и реализовывать простые API.

## Задача проекта
Разработать REST API с двумя методами:

GET /entities?keyword=... – поиск по ключевому слову,

GET /entities/{id} – получение деталей по ID,

и др.

## Технологии:
C#, .NET 8+,
Данные хранятся в бд,
Используется Swagger для документирования API.
